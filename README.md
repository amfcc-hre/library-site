# AMFCC Library

Catalogue and circulation site for Library Staff, School Administration, and IT Administration.

## Upload

Upload every file in this folder to the root of the Library GitHub Pages repository. Keep the filenames and folder level unchanged.

## First setup

1. IT Administration must set the **Library Staff** PIN before staff can log in.
2. The catalogue starts empty. Add titles, then add each physical copy with its own barcode.
3. Review the default rules: 14 loan days, 3 active loans, and 1 renewal.
4. No fines or reservations are included in this first version.

The public catalogue exposes only title and availability information. Borrower records require a protected library session.
